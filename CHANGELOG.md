# Changelog

All notable changes to KITTEN FRONT are documented here.

## 0.1.0 - 2026-10-10

- First public prototype.
- Real-time dot warfare with drawn movement paths and a dynamic front line.
- Campaign, skirmish, scenarios and four special game modes.
- Nation, research, production, supply, morale and defensive combat systems.
- French and English interfaces with persistent settings.
- First-launch presentation hosted by Commander Whiskers.
- Save games, autosave, Windows packaging and installer automation.
